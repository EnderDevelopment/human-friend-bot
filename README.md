# HumanFriendBot

HumanFriendBot is a Discord bot designed to simulate human-like interactions and movements within a game environment. It can follow designated players, perform dance moves, jump over obstacles, and engage in simple, appropriate conversations. The bot is controlled through Discord commands and can be selected from a list of players in the UI.

## Install

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/HumanFriendBot.git
   cd HumanFriendBot
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file in the root directory and add your Discord bot token:
   ```env
   DISCORD_TOKEN=your_discord_bot_token_here
   ```

## Use

1. Start the bot:
   ```bash
   python bot.py
   ```

2. Use the following commands in your Discord server:
   - `!follow <player_name>`: Follow the designated player.
   - `!emote <number>`: Perform a dance move with the given emote number (1-8).
   - `!jump`: Jump to pass through obstacles.
   - `!list_players`: List all players in the UI.
